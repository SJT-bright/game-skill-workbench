# 局部按钮组：先反例回放，再检查修复

适用于已出现的按钮互压、贴图越界、长标题被截断；只检查受影响整页和同组控件，不扩成全游戏 CI。

1. 保留未修运行副本。候选检查流程先放项目的临时目录，禁止仅改正式规则便声称有效。固定同一组语义入口，在实际手机视口等异步贴图、Widget 和动画稳定后保存同帧截图与真实 Sprite 框。连续 3 次采样每边变化不超过 1 CSS px；目标初始为空不算通过。
2. 采集已有 prefab 节点与动态创建入口实际走到的分支。尺寸代码不能只写在“没有节点才创建”的分支；已有节点也必须执行适配。检查 RAW Sprite 换图后的原始尺寸、父子缩放和按下/松开恢复值。点击根框正常不代表其子图正常。
3. 将本组所有可见 Sprite 的四角经世界矩阵、相机/Canvas 视口换算为 CSS 屏幕坐标；检查实际图框、画布边界和跨入口覆盖，默认容差 1 CSS px。不用工厂目标宽高、点击框或单节点裁图代替整页合成画面。图集透明边/旋转等使矩形与截图不符时先校准，不按错误矩形改图。按钮自身底板与文字按同一语义 owner 归组，跨 owner 的实体底板或标题互压不豁免。
4. 同一 checker、同一入口在未修版必须命中当前重叠/越界，修复版在受影响的两种手机比例均无该问题；分别保存截图 SHA、当前业务 bundle SHA、真实采集框和结果。加载失败、空采集或缺截图只能报不可检查，不能充作“成功拦截旧缺陷”。候选未检出旧版时继续修流程，验证有效后才写入正式 Skill。
5. 打开整页和含邻控件的局部截图确认几何结果；真实点本组入口，读回对应反馈，松开/刷新后不得重新放大。只需复查本组，更新手机框预览并清理测试空间。

辅助检查器：`python3 scripts/check_button_group.py CAPTURE.json [...]`。退出 1 表示发现问题或材料无效；退出 0 才表示提交的采集无所查几何错误。它只检查局部几何，不代替图像内容审美或完整美工验收。

采集格式：`producer: real_cocos_sprite_geometry`、`viewport: {width,height}`、`bundle_sha256`、`screenshot` 绝对路径与 `screenshot_sha256`、非空 `groups`。每组含稳定 `slot`、实际节点 `path`、非空 `sprites`；每 Sprite 含 `rect:{x,y,width,height}`（CSS、左上原点）、`frame`、`loaded`、`node_size`、`scale`、`size_mode`、`original`。无可信运行采集器时保留未检查，不手填通过。项目 collector、反例截图和补丁留项目，不写入通用 Skill。
