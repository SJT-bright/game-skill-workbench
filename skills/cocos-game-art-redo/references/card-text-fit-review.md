# 卡片与列表文字贴边短检

用于卡片标题、状态字、列表标签显得贴边、被裁断或压住插画的局部美工问题。只检查受影响的页面与组件组。

1. 保留未修复版本。进入用户指出的精确页面/状态，等异步贴图与布局稳定后截整页；若用户截图被裁过边，另截实际完整游戏画面，区分游戏裁切和截图裁切。
2. 在 390×844 与 375×812 两种手机视口检查真实字形，优先看最长标题、状态行和最外侧卡片。看字形相对卡片内边框、插画、邻卡和屏幕边缘的位置；不能只看 Label/节点宽度或单节点裁图。
3. 任一字形被裁、压住插画/边框、碰邻卡或没有清楚的内边距就判失败。先用同一规则检查未修复截图；如果旧版没有被识别为失败，先修正检查方法，再改游戏。
4. 只调整受影响的换行、字号、文字框位置或卡片留白，保留完整文案与功能。用相同页面、状态、视口重拍；所有字完整、与插画/边框分离且留有可见内边距后，结束本次局部复查。
5. 当前输入不是 Cocos Creator 工程、`art_check.py` 拒绝运行时，可用项目已有的浏览器兼容预览作局部视觉诊断；明确记录它不是 Cocos Native/设备验收，也不把它写成正式美术门禁通过。

记录未修与修复截图、视口、对应业务 bundle SHA、问题位置与结果即可；不为这项局部检查生成整套页面盘点或重跑 CI。

边框占比膨胀、主体很小、连续大空隙或邻格碎片同时出现时，转[装饰卡片内区与切片短检](card-ornament-layout-review.md)，不以外框/文字框在屏内代替内部实景检查。
