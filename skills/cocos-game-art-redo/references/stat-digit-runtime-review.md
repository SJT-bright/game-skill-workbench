# 资源数字实显短检

适用于资源数字过小、同组忽大忽小，或状态值正确但截图像多出一位。沿用既有数字字芯 22 CSS px 目标，不另设一套字号规则。

1. **量实显，不看名义字号。** 贴图与布局稳定后，同帧记录容器 `width/height`、可见底板框、旧 Sprite 的 `sizeMode`、逐字 SpriteFrame/Alpha 紧框及换算后的 CSS 字芯高度。`getBoundingBoxToWorld` 会包含子节点，不能代替布局容器尺寸。绑定实际业务 bundle 与字形纹理，不只记录通用 `main.js`。
2. **把状态、字形和切片逐位对上。** 截图像多出数字时，先核对原始状态值和每位实际 SpriteFrame，检查切片是否夹带邻字、边缘残片或透明留白；不能直接据截图修改关卡总数。Alpha 多连通块仅提示复核，须用真实坏字形和正常字形校准，不能把合法分离笔画一概判坏。
3. **稳定尺寸后排整组。** 布局由代码管理时，旧 Sprite 即使禁用也要核对异步贴图后的尺寸；按实际情况改为 CUSTOM 或移除其尺寸控制。用透明边界归一化字高、按自然宽度排字，整组避开图标和缝线；检查短值、宽字、分隔符与最长显示形式，不能用逐字固定窄格把字号再次缩小。
4. **先反例，后采用。** 同一采集器/判据须拒绝未修版、空或未完整加载的采集及已确认的字形残片；修复版与正常字形对照通过后，再看最小手机比例和另一比例的整屏与原尺寸局部。记录每个受影响页面的实际值、最小字芯高度和内区/字距结果；使用图片字或数据值正确不能单独记为通过。
