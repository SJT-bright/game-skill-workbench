# 动态文本缺字与回退短检

适用于乱码、方块、缺字、异常符号，或动态文案退回系统字体的局部修复。完整制作在试玩前覆盖本游戏实际存在的成功/失败结算；仅原包试玩不因此扩为全量验收。

- 检查最终可见节点，不以配置、源码文字或累计 fallback 日志代替。等待异步字体/贴图稳定，逐个核对实际字符串、字体绑定与 Unicode 字形覆盖；数字、正负号、分隔符、括号、逗号及换行组合一起检查。多行/混排不得静默绕过图片字渲染；字体未到、空采集和不可见节点不能记通过。
- 字表覆盖不证明纹理正确：同时看整页与原尺寸局部，查 glyph→纹理区域、邻字残片和实际显示。系统字体是否允许按当前美术契约判断，不能把任何系统字体一概叫乱码；无法复现用户具体坏字时如实说明。
- 同一判据先拒绝当前故障版，再验修复版；另用一个已知缺字反例与合法符号对照校准。检查实际共享的成功/失败分支及重开后状态，绑定当前业务 bundle 和截图，只复查受影响范围。修复不得靠删掉有业务含义的字或改存档数值。

本例的漏检原因是只验首页/进关，混排器遇换行整段回退，旧 fallback 日志又未区分暂态和最终态。项目采集器与反例留项目，通用 Skill 不写游戏坐标。
