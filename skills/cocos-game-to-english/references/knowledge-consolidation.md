# 完工知识整理、去重与通用化

用于用户确认一款游戏完成、通过、结案，或要求把本轮问题沉淀进 Skill 的收尾阶段。目标是维护一套可复用的机制规则，不保存聊天流水账，也不把单款游戏的实现细节升级成通用要求。

## 固定流程

1. 读取当前项目权威实体、问题历史、修复记录、测试证据和现有相关 Skill；先列出本轮确实发生过的反馈、根因、修复、验证结果和未验证边界。
2. 为每条候选结论抽取稳定机制：触发条件、玩家可见症状、根因类别、正确修复原则、验证后置条件和适用范围。删除角色名、关卡号、按钮名、皮肤数量、价格、路径、版本号、平台账号和项目专属文案。
3. 在现有 Skill、references、assets、scripts 中按“同一机制/同一失败判据/同一修复动作”检索旧规则。相同规则只保留一个规范条目；新证据更完整时合并并替换旧条目，不能在旧条目后继续追加同义段落。
4. 对重复、较弱、过时或与新证据冲突的内容执行删减或改写：
   - 同义重复：合并为一条，保留更短且判据更清楚的版本。
   - 新规则覆盖旧规则：更新旧条目并注明适用边界，不保留两套并列要求。
   - 只描述某个项目的旧事故：移到项目 Wiki/证据，Skill 只保留抽象机制。
   - 已被现行规则取代的旧流程：删除旧流程正文或明确替代关系，避免后续同时执行。
   - 只有历史证据价值、会误导执行的内容：从执行入口移出，留在项目历史记录。
5. 只把跨游戏可复用的规则写入 Skill。规则必须说明“适用于什么机制、如何触发、看什么结果、何时不适用”；没有对应机制的游戏记录 n/a，不新增功能来满足清单。
6. 每条新增或修改后的规则必须能指导实际修复和回归：保存旧失败判据，定位产品/测试工具/平台边界，修复根因，保护业务不变量（基础奖励、存档、所有权、当前页面和旧回调隔离），用同一操作验证旧失败、修复版和正常对照，再接入实际检查器或 writer；若当前工具仅能人工观察，明确记为未自动拦截，不宣称已接入。无可取得的旧版本时标证据缺口，可用经说明的同缺陷反例，不能伪造旧失败。
7. 完成后做一次反向审查：同一问题在 Skill 中只能有一个规范来源；入口 Skill 只做路由，详细规则放一个 reference；项目名称只出现在项目证据，不出现在通用执行规则；删除一段规则后全文没有失效链接、重复编号或引用旧版本的相反要求。
8. 运行 Skill 格式校验、引用/JSON/脚本语法校验和一个轻量去重检索。只报告本轮确实改动和验证的内容，不把历史聊天长度、重复读取次数或缺失 token 当作项目事实。

## 维护原则

- Skill 是可维护的规范，不是越来越长的事故档案。
- “已有相同问题”先更新原规则，再决定是否保留新证据；默认合并，不默认追加。
- 项目 Wiki 保存完整来龙去脉、版本、截图、SHA 和未验证边界；Skill 只保存能让下一款游戏少犯一次同类错误的最小机制规则。
- 如果候选内容无法抽象到另一款游戏，拒绝写入共享 Skill，并把它留在项目文档。

## 给其他 AI 的可执行防错报告

用户要求把返工经验交给其他 AI 时，在项目交付目录产出一份可独立阅读的报告；共享 Skill 仍只保留本节格式与各机制的唯一规范，不复制项目事故表。报告应包含以下内容：

- **任务合同**：输入类型、准确引擎、已确认版本、允许改变的内容、必须保持的玩法/美术/免费规则、所要交付物。先将源码、Web、Native 和上传 ZIP 分清；用户要求仅英化时不能顺手重做画风或玩法。
- **机制与失败判据表**：每行写触发步骤、错误症状、已证实根因或待核假设、正确处理原则、必须读回的业务结果、适用范围、现有规范/检查入口。不能用“注意适配”“加强测试”等句子代替可执行判据。
- **最小交接证据**：同一个失败输入、故障版或说明过的反例、修复版通过、正常对照、实际生产依赖和版本绑定；人工视觉检查写明尚未自动拦截。使用真实业务实现及实际场景绑定，不能以复制的简化实现证明自己。
- **执行顺序与停止条件**：先核输入/资源/版本，再打通首个真实流程，再按受影响机制补异常状态，最后出包和独立核验。加载、保存或已知反馈失败时先修对应原因；普通“继续/打包/快点”不等于授权跳过失败。不得另写候选脚本接受失败返回码、给 pending 加白名单，或用改名/新报告绕过当前必需检查。明确缩小任务范围时使用已有适用路线，真实缺口保留，不能把局部通过称完整验收。
- **不作零缺陷保证**：目标是使已知错误在交付前被检出，保证的是执行过的范围和可追溯结果；不承诺不同引擎、所有设备或未知机制一次生成永不出错。每个新增反馈回到对应机制和最小回归，不要求下一款游戏照搬本款界面、数值、关卡或固定坐标。

报告中的“用户确认通过”单列日期、原话和产物身份。不得据此倒填以前未执行的测试、具体设备、真实广告或后台发布；也不要在结案后为补历史表重做已确认且未变化的游戏。
