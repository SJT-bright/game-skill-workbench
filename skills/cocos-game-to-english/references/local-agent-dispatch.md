Grok按[可选CLI](optional-grok.md)独立开关；完全单应用不派外部，主Agent+可选Grok只走窄CLI，不打开六桌面应用。缺Grok由主线或已选合格执行者承接，仍独立验收。

# Cocos制作的本地多应用执行

新任务先询问主Agent+可选Grok、桌面多Agent+可选Grok或完全单应用；本轮人类明确要求调动时视为已选择，未答复不派发、旧轮选择不沿用。只有选择启用后，加载已安装[桌面总控Skill](../../desktop-agent-orchestrator/SKILL.md)，按其[委派边界](../../desktop-agent-orchestrator/references/delegation-boundaries.md)及[实时应用路由](../../desktop-agent-orchestrator/references/local-app-routing.md)实际派发。不复制聊天到每个应用，不把阶段整体外包；每个阶段都拆主线决定、执行文件权和原始证据。只讨论/改Skill时不启动别的游戏。

## 谁做什么

需求、任务输入/输出和原始验证按[任务证据](production-plan.md)引用现有合同；每执行者一个当前任务，主线维护依赖和唯一规格/进度写者，独立且锁不冲突时可并行。本页现有角色、关键文件保护、权限与验收仍为准，不另加一套委派制度。

| 制作阶段 | 主线必须亲自决定/审查 | 可派批次及默认候选 |
|---|---|---|
| 0 源码基线 | 选精确原包/目标，决定保留约束/引擎路线，登记关键保护路径 | WorkBuddy：A01–A05原包/基线/字段/资源/候选清点；工具具备时OpenCode/AStudio备选 |

| 2 UI与共通部件 | 方向、布局/状态表、真实业务接口；内置image_gen与原件选择 | Qoder CN：B02–B03独立UI/图片接线；WorkBuddy：A07归档/字节；AStudio/Qoder备选，不让执行者自行画通用方框替代 |

| 4 功能/触屏 | 玩法/教程/复活规则、关键输入/相机/物理根因与补丁，设计完整矩阵/断言 | Qoder：B04非关键已定补丁/B06参数化用例；OpenCode：A10固定回归；独立QA按B05采可信touch/状态 |

## C域保护与真实验收

逐游戏定位广告服务、存储/奖励账本、输入转换/相机、核心玩法/物理、公共入口和测试断言等关键文件；主线登记保护范围。UI文件混有这些关键逻辑时，主线持有整文件，先抽出独立UI边界再交执行者；不能把架构分离本身未经判断交作“简单重构”。C域根因/设计/关键补丁默认主线亲自处理，不以“总控不写代码”外包。

所有任务固定源/规范SHA与输出目录，独立证据标明版本/环境/工具。SDK替身、模型方法、真实Cocos GUI、可信触摸、物理手机/真实IAA分别记，不能因换一个AI应用就提升证据等级。当前 catalog 的全部检查ID及既有门禁保持，委派不会新增例外或给pending改pass。

实现者、固定回归者、GUI证据者、独立包核验者按唯一文件/资源锁协作，主线最后查看关键原证据并裁定。执行者发现新问题保留失败，交主线明确修法后再实施，不无限自行研究；QA不能直接改业务/断言“修好”后自行通过。

台账、任务书和检查器属于[桌面总控Skill](../../desktop-agent-orchestrator/SKILL.md)，本页只维护游戏阶段映射。换电脑先按其迁移说明核依赖和实际应用路径；不复制旧会话ID、登录态或原作者路径。通道不可用时推进主线C项与A类确定性工具，不扩大低水平模型的判断范围。当前安装更新不等于旧窗口已加载，也不等于所有应用已送达/开工。
