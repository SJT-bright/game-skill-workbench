# 不压垮电脑：被占就开新的、旧的空了就关

同时跑的东西太多会把电脑拖慢，最常见的瓶颈是**内存**（用户 2026-10-20 提出）。以下规则供加载本 Skill 的游戏任务使用，检查标准不降低。用户当前指令和全局 AGENTS.md 优先；不宣称已打开聊天自动同步。

**同时干活的子会话数按内存定**（视觉与测试线也算）：内存 ≤16GB → 2 个；17–48GB → 3 个；更大 → 4 个。总控开工时跑一次 `cleanup_machine.py`，它会报出本机内存和建议数量。

## 一、遇到"被占用、要排队"：立刻新开一个，绝不等待（用户 2026-10-23，最高优先）

用户 2026-10-22/23：测试的 AI 说"音量复核被另一项正在运行的游戏测试占用了资源锁，暂时还没轮到执行，我会等这一步跑完"。**这是明令禁止的做法。** 尚未绑定资源且只是普通并发争用时，采用下面的方法。自己绑定的测试空间失活/未分配时，停止旧 ID 操作、核实它从列表消失，再自动新建并登记独立空间继续，不询问用户、不接管旧 ID。用户明确接管、要求停止或安全 hard stop 则立即停止对应操作，不能换空间、接口或系统信号绕过：

1. **不等待、不轮询、不跟用户说"在等"**：不写"等轮到再做""等那一步跑完"，不 sleep 后再查、不反复看 `status`。
2. **立刻在 Ego 里新开一个独立窗口**：被占的是谁都一样——别的游戏的测试、同一个游戏另一条线的测试、别的会话的 TaskSpace、别人的预览服务、"手机模拟页"——都不去抢、不去等，自己**新开**一个：
   - 自动测试：直接跑 `chrome_touch.py --user-approved-chrome --channel chrome --name "<线名+做什么>"`，每次运行在 Google Chrome 里建立新的隔离窗口；多个同时跑互不影响；
   - 需要手动操作 Page 时：用 `ego-browser nodejs` **新建一个只属于本会话、本次测试的 TaskSpace**（不复用别的会话的空间，不 `claimTaskSpace` / `takeOverTaskSpace` 别人的空间），打印 spaceId 后登记：`python scripts/browser_slots.py register --kind ego_space --space-id <ID> --name "<线名+做什么>" --project <工程>`；
   - 预览服务被别人占着或正在被构建改写：自己开一个新的，`python scripts/serve_preview.py --directory <最新一次完成的 Web 导出> --snapshot --no-browser --name "<线名>"`（自动选新端口；`--snapshot` 先复制一份私有副本，正在跑的构建改不到它）。
3. **每次新开之前先查旧的、空了就关**：`python scripts/browser_slots.py sweep --close`（`chrome_touch.py` 和 `serve_preview.py` 启动时会自动先做这一步）。它逐个检查以前开过的测试窗口、Ego 空间和预览服务：
   - **登记的拥有者进程已不存在**（会话结束、脚本崩了）→ 退役记录；旧Ego空间仍需核当前归属，不能盲接管；
   - **已完成的自有资源** → 经当前进程启动身份核对后正常退出并注销；已交用户的Ego页按受支持接口核归属；
   - **疑似卡住**：测试窗口 20 分钟没有任何一步、Ego 空间 30 分钟没用过、预览服务 30 分钟没人访问 → 列待核候选；仍活着的任务不能仅因心跳年龄关闭；
   - **还在干活的（别的会话正在跑的测试、给用户的 Codex 本地预览 `serve_preview.py --keep`）一律不动。**
   Ego 空间须由当前拥有者通过已绑定的官方 API 结束。`close` / `ego-finish` 只读当前空间列表核对原 ID 已消失后注销；仍存在、列表不完整或 API 失败时退出码 2、记录保留。不根据旧 ID 自动接管空间，也不输出盲接管代码。
4. **自己用完马上关**（见下一节，所有环节都一样）：`chrome_touch.py` 跑完自动关自己的窗口并注销；手动的 Ego 空间、预览服务测完马上 `browser_slots.py close --name "<线名>"`。
5. **电脑很满也不等**：`sweep` 会报 `active_windows`（正在开的测试窗口数）和 `soft_cap_windows`（≤16GB 4 个，17–48GB 6 个，更大 8 个）。超过时先关**本线自己**已经不用的窗口，然后**照样新开**，不去等别人、不去关别人还在用的。

### 测试用完就自己关浏览器（用户 2026-10-23，所有环节）

用户定：**无论哪个环节，测试用完了 Ego 浏览器，都要自己关掉对应的浏览器。** 英化和重塑都一样，接入测试、按钮点测、加载测试、录屏、批量跑关、截图审美术、打包前手机审查、最终验收、修完复测，每一次都算。

1. **一次测试做完就关，不攒、不留给以后**：不等下一次 `sweep`、不等 20/30 分钟自动关、不等总控收尾、更不让用户去关。
2. **关的是"这次测试开的"**：
   - `chrome_touch.py`：正常路径关闭自有 context 并读回成功后注销。异常或中断造成关闭未确认时保留 `cleanup_pending` 和资源记录，拥有者用原受支持接口核实并处理，不能把辅助进程退出当窗口已关。
   - 手动 Ego TaskSpace：先核当前控制权，用已有 task 绑定 `finish({keep:[]})`，读回列表确认消失，再 `python scripts/browser_slots.py close --id <slot>` 注销。预览服务用 `close --name "<线名>"`（也可 `--id`）；脚本核当前进程启动身份、正常退出并验证原实例消失后才注销。退出码 2 表示关闭未确认，保留记录继续处理，不将失败计为通过。
   - 没登记过的（忘了 `register`）：自己记下 spaceId，用完照样 `finish`。
3. **汇报前先查**：汇报"测试完成"、写交接、交给下一条线之前，跑 `python scripts/browser_slots.py check --name "<线名>"`，**退出码必须是 0**（这条线开的东西都已关）；不是 0 就先关再汇报。
4. **Ego 没有例外**：用户试玩不在 Ego（见下一节），所以 Ego 里这次测试开的窗口和空间一律关。唯一可以留着的是给用户的 **Codex 本地预览服务**（`serve_preview.py --keep`）：`close --name` 默认不关它，用户说玩完（或下一轮开始）就 `close --id <slot>`（或加 `--include-keep`）。
5. **只关自己的**：别的会话、别的线还在用的窗口不动；Ego 程序本身不关，只关这次测试开的窗口/空间。

### Ego 只给 AI 自己测试，用户试玩一律在 Codex 本地预览（用户 2026-10-23）

用户定：**只有 AI 调用 Ego 浏览器做测试的时候才算使用 Ego；交给用户测试的时候，一律在 Codex 上给本地预览。** 所有新建的 Ego 窗口、TaskSpace 都只用于 AI Agent 自己测试。

反例（用户截图）：Ego 的空间列表里堆着"需要你处理 · HSS-v2-user-preview""需要你处理 · Battle Cars v7 local preview"这种等用户去试玩的空间；AI 汇报"试玩页已在 Ego Lite 中打开并交给你操作，看到 Swipe to Play 后滑动即可开始"。**这两种都禁止。**

1. **禁止一切在 Ego 里让用户试玩的行为**：不开"给用户试玩"的 Ego 窗口或空间；不把页面置前、不 `handOff()` 给用户；`chrome_touch.py --handoff` 已停用（直接报错）；`browser_slots.py register --kind ego_space --keep` 会被拒绝；不在回复里写"已在 Ego 里打开，交给你"。
2. **用户试玩怎么给**：`python scripts/serve_preview.py --directory <最新一次完成的 Web 导出> --keep --name "<线名> 用户试玩"`（默认不自动打开任何浏览器），把打印出的 `http://127.0.0.1:端口/` 交给用户在独立 Google Chrome 中打开；Codex 内置浏览器只可查看，不能作为手机触摸测试；同时写清"这是竖屏/横屏游戏"、建议的窗口尺寸和怎么操作。这个预览服务用户玩完就关（`browser_slots.py close --id <slot>`）。
3. **历史 Ego 空间先核用途再处理**：用 `python scripts/browser_slots.py ego-list` 只读取得列表。名称含试玩或显示“需要你处理”只作为候选；核实已完成、取消或被新版替代且不再使用后，通过受支持的当前拥有者接口结束，再 `ego-finish --space-id <ID>` 读取列表核对原空间消失。用户当前在用、明确要求保留或未知归属不动；遇到工具 hard stop 立即停止。新任务不再为用户创建 Ego 试玩空间。集中移出按现有十小时自动化，不在本次 Skill 更新里运行真实清理或新增循环。
4. **AI 自己测试照常用 Ego**：触摸计划、截图、录屏、批量跑关、加载测试、手机模拟都还在 Ego 里，后台跑，测完马上关（上一节）。

### 只有一种情况需要先后顺序：同一个游戏"写文件"的活

同一个游戏的**构建/导出、音频流水线**会写同一批文件，两份同时写会把工程写坏，所以只有它们按游戏排队：

```
python scripts/heavy_lock.py run --project <这个游戏的文件夹> --name "<线名 做什么，如：组装线 web 构建>" -- <原来的命令>
```

- 这条命令**放后台跑**，排队由脚本自己完成；模型不等它、不查它，接着干别的。
- **测试从不等构建**：要测的时候，用最新一次已完成的构建开新的预览（`serve_preview.py --snapshot`）、新开测试窗口，马上测；新构建出来后再按影响复测。
- 不想排队时加 `--no-wait`：同一个游戏正在写就立刻返回 75，按上面的办法先测已有构建。
- 不同游戏之间**从不互相等**；不写 `--project` 时不排队、直接运行（全机锁已取消）。
- 测试和检查命令（`chrome_touch.py`、`serve_preview.py`、`ego-browser`、Playwright 脚本、`audit_*`/`check_*`/`test_*`、录屏分析、批量跑关）**不要用锁包**；包了也会直接放行，不等任何锁。
- Cocos 编辑器界面（打开场景、手动构建）同一个工程只能有一个会话在用；测试不需要编辑器，用命令行构建即可。编辑器被占时不等：先做轻活或用命令行构建（同样走上面的按游戏排队）。
- 启动加载计时（LOAD-03）在电脑很忙时可能变慢：超标时先看 `cleanup_machine.py` 报的占用，忙的话重测一次再判定。

## 二、少开、早关

| 东西 | 规则 |
|---|---|
| Codex 子会话 | 同时在干活的不超过上面按内存定的数量；做完的线写完交接就结束，不挂着等 |
| Cocos 编辑器 | 只开一个；没人用时关掉。能用命令行构建时不开编辑器界面（2.4：`CocosCreator --path <工程> --build "platform=web-mobile"`；3.x：`--project <工程> --build ...`，参数以官方文档为准） |
| 测试浏览器 | 每次测试在 Ego 里新开自己的独立测试窗口，后台运行，可以同时多开，**被占就新开、从不排队**；新开前 `browser_slots.py sweep --close` 关掉空了的旧窗口；（用户同意用 Chrome 时）自动测试 `--headless`；**Ego 只给 AI 测试，从不置前交给用户**（用户试玩用 Codex 本地预览）；脚本结束自动关闭自己的窗口；**手动开的空间/预览测完马上 `browser_slots.py close --name <线名>`，汇报前 `check` 通过（所有环节，用户 2026-10-23）** |
| 本地预览服务 | 每条测试线自己开（新端口，`--snapshot` 用私有副本），不共用、不等别人的；20 分钟没人访问自动关闭；测完马上关（`browser_slots.py close --name <线名>`）；给用户试玩的本地预览加 `--keep`，链接写在 Codex 回复里，用户玩完就关 |
| 音频 | 素材库索引默认只用一半 CPU 核心（最多 4 个）；音频流水线走这个游戏自己的锁（`--project`） |

## 三、少构建

- 修改**攒一批再构建**，不要每改一处就导一次。
- 平时测试只导出 **Web 版**；**Native 版只在用户说"打包"时**才导出。
- 同一份源码已经构建过、源码没变时，不重复构建（`check_input_snapshot.py` 判断哪些变了）。

## 四、硬盘别堆满

- 录屏分析加 `--delete-frames`：保存好证据图后删除帧文件夹（证据图才是要看的）。
- 每个游戏只保留**最新一版**的测试截图、录屏和报告，以及**所有失败记录**；被新版本取代的旧截图/录屏在收尾时删除。
- 交付 ZIP 只保留当前版本和用户确认过的版本。

## 五、开工前、新开窗口前、收尾时各跑一次清理

```
python scripts/cleanup_machine.py           # 先看有哪些遗留（不动任何东西）
python scripts/cleanup_machine.py --close   # 关掉空了的旧测试窗口/空间/预览服务和没人管的遗留进程
```

它先做一次 `browser_slots.py sweep`；仅对已完成、登记身份匹配的自有进程正常退出并核实。旧 Ego 空间、只有心跳超时的活资源、未登记历史 PID 和父进程已不在的孤儿只列待核候选，核当前归属与用途后再处理。正在运行的其他会话、用户自己的 Chrome、Cocos 编辑器和 Codex 不动；持续 CPU 过载按全局 AGENTS.md 的三次差值采样阈值处理。


融合后的清理边界：独立窗口/端口和私有快照继续使用；完成的自有QA正常退出并注销，读回空间/页面/端口确已消失。`--keep`保留的用户试玩不因固定小时数到期关闭；用户玩完或新版替代后，由 Agent 关闭并核实，不让用户手动清理。自动清理只处理登记中已完成且进程启动身份匹配的资源，或退役已不存在的拥有者记录；仅心跳超时仍在运行、旧版未登记PID、未知所有权只列待核候选，经支持的界面确认确实无用后再处理。自己绑定的测试空间消失，核实旧 ID 已不在列表后自动另开独立空间；用户明确接管、要求停止及工具安全 hard stop 立即停止，不换空间、接口或系统信号绕过。
