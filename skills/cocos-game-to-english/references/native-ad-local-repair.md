# 本地修复 Native 广告前置故障

适用于玩家点击广告无响应、商店/奖励提示无法读取数据、模拟成功而 Native adapter 失败。只修本轮相关链，不扩大玩法或强加新广告入口。以下本地门槛通过即可关闭对应本地缺陷；真实平台填充按现行 tiktok-device-stage.md 的边界处理，不要求用户扫码来完成本地任务。

1. **先定位停在哪一段。** 在独立测试宿主采集真实触摸、存储读取/写入、SDK create/show/close/error 和原业务消费者。SDK 调用前已失败属于前置业务/存储故障，不能写成无填充。观察要来自当前 Native 执行；不得 evaluate 调用按钮回调、直接发奖或改余额来证明链路。 必须记录实际命中的 `TTMinis.game/tt/wx` 与存储桥：Web 注入 `wx` 会掩盖 Native 走 `tt` 或 adapter fallback 的差异；界面相同不代表调用路径相同。超时/取消后旧会话锁与音频占用须释放，再次真实点击必须增加 SDK 请求，迟到回调不得影响新会话。
2. **存储替身必须忠实。** 在生产 adapter 实际调用的接口注入，明确 tt 或 TTMinis.game；种子存档、getStorageSync 与 getStorageInfoSync.keys 必须一致。分别测缺键返回 Boolean、已存在的 Boolean、有效旧档、损坏值、读失败、键列表失败和写入失败。键是否存在与值是否合法分开判断；不知道是否缺键时不写默认值。每个字段按其整数/JSON/Boolean 合同解析，不全局将 true 变 1。非关键显示组件可降级，但不能因读失败覆盖存档或产生未处理异常。
3. **能力检测也要对照。** 测目标广告函数存在且 canIUse 缺失、明确 false、抛错及两个命名空间。依据目标 SDK 契约确定兼容策略；显式不支持时保留反馈，函数存在且无能力查询时不能无依据一律判 unsupported。命名空间替身的 canIUse 必须查询该对象，避免测试工具误报。
4. **跑完整的本地广告会话。** 当前可见按钮真实触摸后，完成只发一次；取消、拒绝、创建失败、不可用、超时不发广告增量。连点/重复与迟到回调不重复发奖；超时后再次实际点击必须可发起新请求，不能被未确认标志永久锁住。覆盖完成后写失败→同按钮重试保存，不能再播一次或多领一次。保存读回、重开保持、原道具/货币实际使用和返回后输入恢复都要观察。测试替身只放独立 QA 宿主，不能进入游戏/上传 Native。
5. **校准失败对照。** 同一宿主、同一真实输入和相同业务断言，旧故障应有明确错误业务结果；宿主崩溃/错误注入/点错位置不算复现。修工具后重跑受影响证据，不给旧日志补版本标签。保留旧故障、修复与有效数据正常对照及其生产字节。
6. **绑定证据。** adapter 形态矩阵按 ad-storage-evidence-contract.md v2；玩家链结果另保留逐入口的实际变更、SDK 次数与当前 Native/runner/宿主身份，并登记现有问题账本的可执行 retest。只有材料检查通过不能标玩家链通过；只列测试数量不能替代业务结果。

官方接口参考（2026-10-27核验）：[Storage](https://developers.tiktok.com/docs/en/mini-games-sdk-storage) 返回任意存储内容并提供 keys；文档未保证缺键返回 false，不能把注入假设当平台事实。[IAA](https://developers.tiktok.com/docs/en/mini-games-sdk-iaa) 的 show Promise 表示展示结果，观看完成以 onClose.isEnded 为准。平台接口变化时复核文档与实际 adapter，保留本地假设和原机观察的区别。
