# 分享与排行榜前置禁用（用户 2026-10-24）

适用检索词：美化游戏、只改美工、重做美术、重塑游戏、玩法设计、英化、检查、出包；Share、Invite、分享给好友、邀请好友、好友排行、排行榜、Ranking、Rankings、Rank、Leaderboard、League。

## 开始前执行，禁止等到最后检查

用户明确要求：游戏内分享与所有排行榜同等禁用。包括好友/世界/地区/周榜、联赛/段位榜、本地模拟榜和假榜；有真实功能也删除。原游戏自带、老优化方案写了保留、旧 decision=add/keep_original、附件策划包含排名，都不能继续启用。不得反复询问是否保留；后续当前用户明确改变本条时才重新处理，旧记录不算新指令。

- 美化/重做美工：在页面清点、设计方案、素材生成之前，先盘点并移除分享、排行榜；这是本条明确授权的功能清理，不因“只改美工、不改功能”保留它们。其他玩法、经济和已确认美术保持本轮范围。
- 重塑/玩法设计/英化：在读入原游戏或启动包、制定 modules/screens/UI_PAGES 和玩法方案时，先标记禁止项并排除，不设计排行榜页、奖杯排名按钮、好友分享及其奖励，不生成相关素材，不将其列为可选功能。
- 检查/出包：先检查禁用规则，再按本轮范围执行其他门禁。全部排行榜禁用；不能仅检查空排行榜，不能用 n/a、maintenance scope 或旧保留标志绕过。

## 清理与复核范围

移除全部可见入口、prefab/scene 实际节点、事件绑定、路由/动态注入、弹窗与二级页面、好友榜开放数据域、榜单拉取/上传/订阅、分享 SDK 回调和奖励分支。关闭后重开、冷启动和热启动均不可重新出现。仅隐藏/禁用按钮、删除一个主页节点、改名“挑战”或“成绩”但保留比较排名功能不合格。

个人关卡进度、普通金币/分数、皮肤、Add to Home Screen、Profile Revisit 本身不是排行榜或分享，不能按 rank/share 子串误删；shared-test 等配置值、第三方引擎的通用适配能力和历史原始资料不等于游戏功能。第三方通用能力若保留，记录归属与无业务调用证据；业务入口与调用仍须删除。平台自身右上角菜单若有分享，核对官方 SDK 的关闭能力并实际验证，不能靠网页预览声称平台菜单已关闭；用户没有提供具体残留入口时先检查现有材料和运行状态，再明确未定位范围。
