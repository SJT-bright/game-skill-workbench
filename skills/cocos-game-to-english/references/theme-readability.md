# 题材一致、舒适亮度与可读性

适用于初版美术与用户反馈维护；与默认画风冲突时，用户本人当前明确的风格和参考图优先。新规则不能把已有项目已授权的局部/UI维护扩大成重写玩法、加关、换存档或重做声音；把本次适用项和未触及的通用项写入项目规格。

- 降低刺眼程度不等于减少设计、不等于白板/纯色方块或系统粗黑字。保留题材的材质、纹饰、轮廓、厚度和信息层次，以柔和漫反射、克制高光、降低局部过曝、调整背景明暗与留白改善舒适度。不要未经用户要求把复杂主题界面简化成通用工具面板。
- 色板和材质由当前游戏确定；不要把某款游戏的石质、古金或青绿推广为所有游戏的强制风格。默认Q版只用于用户未另定风格的情况。
- 固定动作、标题、栏目、物品/任务名按[文字也要设计](page-richness.md#六文字也要设计两个板块用户-2026-10-22)生成完整图片字；按钮的图标、文字和底板同图生成，整套材质一致。动态数字用按画风生成的数字图做成位图字体，配适当描边与柔和阴影，不用整行系统字代替完成稿。
- 小屏文字对比度至少4.5:1，大字至少3:1；描边/底板可以提供对比，但不靠刺眼发光或特粗近黑字解决。说明文字放在图案克制的可读区域。
- 先以首页、地图节点、游戏HUD和一个弹窗做代表样板，在当前真实Cocos中用长短两比例、实际DPR和最终组合自审，再铺整套。查看按钮状态、实际边界、文字拼写、命中位置与图集裁切，不把生图成功当运行通过。
- 更新全局Skill后，当前对话可明确重读新版入口和适用参考；不能宣称其他已打开对话已经同步或完成执行。
