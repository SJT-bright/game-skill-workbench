# Grok 全局后台执行

这是安装在 `<SKILLS_DIR>` 的全局技能，适用于所有加载了此技能或全局规则的项目和聊天。用户明确指定“用 Grok”或“用 Groq”执行任务时，实际调用本地 Grok，在后台工作，不弹出 Grok 聊天窗口或终端窗口。主 Agent 负责理解目标、拆分任务、整合结果、验证和最终回答。

文档命令中的 `<SKILLS_DIR>` 取本次实际加载的 skills 目录，先解析再执行，不沿用其他电脑的用户名或盘符。Windows使用已安装的 `py -3 -X utf8 -B`，macOS使用实际 `python3 -B`；不为示例路径重新安装解释器。

## 触发与范围

- 不要求出现“制作”：只要用户将任务执行者指定为 Grok，就触发。“用 Grok 分析这份材料”“用 Groq 翻译一下”“这一步用 Grok”“让 Grok 来做”“多开几个 Grok 子进程处理”均适用，大小写不影响。在本用户的这种短指令中，`Groq` 按本地 `Grok` 的别名处理；明确指向另一个 Groq 平台或 API 的请求按其实际目标处理。
- 任务从当前消息或已有上下文确定；如果用户只说“用 Grok”，就承接当前待做任务，无需再次确认执行方式。若没有可确定的任务，再询问要处理的内容。只询问能力、讨论或引用触发词、修改技能规则、要求不使用 Grok时，不因此启动无关模型任务。
- 覆盖分析推理、资料整理、摘要、翻译、文案与方案、文件和文档制作、网站与应用开发、代码修改、脚本与检查等当前授权任务，不限制为原文搬取或文件制作。明确指定 Grok 后必须实际调用，不能只口头答应用 Grok、实际全部由主 Agent 完成；失败或接手时说明实际执行者。
- 明确触发是用户对该任务的委派指令；`grok-delegate` 的狭窄白名单仍用于未明确指定 Grok 的自动委派。这次指定持续覆盖当前任务及其修正、补充，用户更改执行者或取消时停止；不自动把所有后续无关任务都交给 Grok。
- 用户未指定模型时使用 `grok-4.7-build-fast`。如指定普通 4.7，使用 `grok-4.7`；模型不可用时报告并继续已授权的准备，不静默换模型或账户。
- 沿用本机 Grok 登录订阅通道，不切换到 API key、不购买额度。主 Agent 的协调也会产生自身用量。以实际回执记录模型、token 和已报告费用；缺失费用写未知，不写零。

## 执行

1. 确认目标任务、输入材料、交付方式和验收方法，读取适用的项目规则。将需要用的原始材料路径或原文交给 Grok，避免先筛选或压缩证据。任务若另有适用技能，提供它的入口路径与必要资源。
2. 单项任务启动一个 Grok 子进程。用户要求多开时，按独立输出拆分并行任务，默认同时运行最多 3 个，可按明确要求调整。不为了凑数量拆开连续决策。不同进程不得同时改相同文件；依赖项按顺序做，共同入口由主 Agent 整合。需要完整项目写入的多个任务使用独立 checkout/worktree。
3. 使用本技能的 [后台运行器](scripts/run_jobs.py)。先读 [任务格式与调用](references/jobs.md)，写各任务的 UTF-8 prompt 和 JSON manifest。每个 prompt 明确输入、允许修改的文件或目录、所需结果与完成判据。分析、翻译等只需回答的任务用结果模式，`write_paths` 和 `expected_files` 均留空；不强迫用户提供输出文件。需要查询资料的任务设置 `enable_web: true`，其他任务沿用默认不联网。制作任务要求直接产出文件并记录验证结果。
4. 用 `exec_command` 启动运行器，**不分配 PTY**，不调用 `open`、Terminal、桌面 Grok 对话框或新 Codex 聊天。运行器以独立 UUID 会话启动 Grok CLI，并关闭 Grok Dashboard 和后台自动更新。通过工具返回的运行 session、日志和 `summary.json` 跟进；工作期间保持正常进度沟通。
5. 所有子进程结果先视为 `completed_pending_review`。查看实际文件、diff、脚本输出，执行与改动相称的检查；可视化交付按适用的视觉验收规则检查。主 Agent 合并、修正并交付；退出码为零或 Grok 自述完成不等于验收。

登录、额度、模型或网络失败时保留回执，说明哪个进程失败；不重复付费盲试、不宣称任务已完成。主 Agent 可修复确定的本地问题或接手必要工作，并说明实际执行者。需要追加 Grok 工作时新建输出回执目录；返工只包含失败或需要修改的部分。

## 边界与生效

本技能使用本地 Grok CLI 的能力和已有权限，不代表已接通 Grok 的 Mac 桌面 `computer use`，也不会自动继承主 Agent 的私有工具。终止运行器会清理它管理的进程组，文件修改不会自动回滚。写入路径是任务分工声明，不能声称构成操作系统沙箱。

指定 Grok 只改变执行者，不增加任务外操作权限；发布、外部发送、购买、安装或替换正式应用按该具体任务已有授权执行，不自行添加。保留既有数据和会话。不能宣称所有已打开聊天已重新加载规则。
