# 原文搬取与认知任务的区别

类型：概念页，2026-09-22。依据 [来源](sources.md)，应用见 [边界矩阵](task-matrix.md)。

- **搬取**：输出值已经逐字存在于指定局部材料，保留原值、上下文位置、条目关系。不能先推理得出新值再称为“提取”。
- **认知处理**：决定重要性、归类、归并、解释、翻译、改写和取舍。即使短小、重复、写成 JSON，仍由主 Agent 完成。
- **感知识别**：从像素读字不是零能力任务。清晰印刷文字可作为 Grok 候选；手写、公式、复杂表格与布局推断不在低认知白名单。
- **覆盖与正确性分开**：返回的每条都有原文，不代表没有漏掉其他重要条目。Grok 不能控制主模型能看见哪些证据。
- **对应关系与字符串分开**：值在原文出现，不代表它属于当前字段或当前实体。脚本不能单凭子串匹配签收语义关系。
- **独立核验**：用原文、结构化源数据、真实运行或主 Agent 实际视觉检查；Grok 自评、重说一次或多个模型一致不等于独立事实。
- **自动性**：主 Agent 加载全局规则和技能后，每个任务自动分流，不需要用户点名；不是将所有任务都派发，也不是后台常驻程序。
- **质量优先**：不保证任何模型零错误；通过避免委派认知步骤、保留原证据、逐项核验和失败接管控制质量。无法有效控制就不委派。
