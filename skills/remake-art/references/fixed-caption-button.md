# 固定英文按钮的生成

适用于有同款无字底、已核准英文整词字图的固定按钮。相同动作、大小写、画风、状态和尺寸已有合格整钮时直接复用。否则按以下步骤合成。比如定稿是 Claim，而词库只有 CLAIM，应先确认设计采用哪个大小写。找不到匹配字图时先制作并逐字确认一次，入库时绑定文字、素材路径和 SHA-256。以后同词、同款复用。模型可负责字形风格与底图，整词拼写由核准词库固定。不得给未经核对的图填上预期单词就视为核准。

1. 读取按钮在最小目标视口的实际显示尺寸，换算到画布像素。沿整行字高取圆角或斜边内侧最窄矩形，留出边距。用同款可读样板定字图最小高度、最大高度以及图标高度、净间距。字图高度含轮廓与阴影，描边过粗或字芯细小要先换源图。底图限定为无字无图标的干净状态。
2. 将下例字段和文件放在同一个项目制作目录。运行 `python3 <skills>/remake-art/scripts/compose_fixed_button.py recipe.json output.png`。矩形依次为左、上、右、下，以底图原点为准，右、下边界不含。只用文字时省略 icon 和 gap。脚本用实际透明像素边界计算，保持比例，在可读范围内取放得下的最大字高，将图标和字作为一组居中，一次写出整钮。没有解时停止，调整按钮或构图后再出图。失败时已有输出会保留，制作流程须以本次命令成功为接入条件。
3. 同一模板和词只生成一次，所有实例复用该文件。把整钮作为一个 Sprite 等比接入，移除同状态原有的视频图标和旧 Label，保留按钮点击与状态绑定；其它状态若文案或图案不同则另建配方。给源图和派生图分别记来源。父节点遮罩、层次与运行时缩放继续按试玩前整页规则核验。
4. 会变的数量或长说明使用真实数据与项目字体度量，在布局前按可用宽度决定换行及行高，验证最长合法值。此固定词工具只合成确定的整词。

```json
{"caption":"CLAIM","base":{"file":"base.png","sha256":"<无字底摘要>"},"safe_box":[17,8,119,37],"gap":6,"icon":{"file":"video.png","sha256":"<图标摘要>","height":17},"word":{"file":"claim.png","sha256":"<核准整词摘要>","approved_text":"CLAIM","min_height":19,"max_height":24}}
```

例中尺寸仅用于 136×45 样板，不能跨模板套用。

依赖 Python 3 和 Pillow 9.1+。从本包 remake-art 目录运行随包示例：

```sh
python3 scripts/compose_fixed_button.py examples/fixed-caption/recipe.json claim-demo.png
```

生成的透明图要裁边时用 `python3 <skills>/remake-art/scripts/trim_visible.py in.png --out out.png`（按 alpha ≥ 8 算包围框，再留 2px 安全边，写 `.trim.json` 回执），别手写 `getbbox()`：生图常留 alpha 1～7 的散点，裸包围框会留一大圈空边（R4O2，合成进化恐龙 NO THANKS/CLAIM）。本脚本的字和图标前景已用同一算法。
生成的字图（整词图、按钮字）收到后裁边一律加 `--word`：`trim_visible.py in.png --out out.png --word` 先用 `clean_glow.py` 去掉描边外的半透明彩色光晕再裁；退出码 1 表示去不掉，按它打印的提示词（同尺寸、同字、no glow）重生成再跑，旧图不接（R4R3，弹球传奇 FREE GEMS/OK 提示词写了 no glow 仍带光晕）。只想查不改用 `clean_glow.py --check`。原游戏的图和缩小过的图集不要跑它（发光特效、带柔和投影的原版字会被当成光晕）。
