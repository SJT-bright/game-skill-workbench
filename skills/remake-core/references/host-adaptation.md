# 本机适配与后续双端融合

共同维护游戏规则、质量门禁、输入指纹、短交接和用量口径。系统只决定路径、命令及进程/浏览器能力，不改变验收标准或用户明确选择。Mac最新版尚未输入时，不宣称已经吸收其后续改动，也不覆盖本机已验证版本。

## 只在有原因时探测

新电脑、首次任务缺少有效环境记录、依赖变化或工具故障时运行；工具正常且版本未变时引用已有记录，不每个阶段重扫。

```text
<当前Python> "<本Skill>/scripts/probe_host.py" --out "<本游戏现有证据目录>/host-new.json"
```

Windows当前Python可用`py -3 -X utf8 -B`，Mac使用已安装的`python3 -B`。占位路径先换成实际加载的SKILL位置及游戏路径。脚本只检查PATH/文件及当前Python，不打开应用、不登录、不执行Grok、不安装软件、不读取凭据；存在不等于可运行或已认证。输出独占新文件，不能覆盖原件。

脚本从自身位置推导skills根；文档里的`<SKILLS_DIR>`同样取实际安装位置。安装目标通常为`CODEX_HOME/skills`，未设置时是`~/.codex/skills`，但显式安装位置优先，不从另一台电脑复制用户名/盘符。项目路径来自当前工作区，不写回全局固定值。

| 差异 | Windows | macOS |
|---|---|---|
| Python/虚拟环境 | 已安装解释器，venv使用Scripts/python.exe | 已安装解释器，venv使用bin/python |
| Grok候选 | PATH，其次用户目录.grok/bin/grok.exe | PATH，其次用户目录.grok/bin/grok |
| 后台进程 | 仅操作运行器创建并跟踪的PID树 | 仅操作运行器创建的新POSIX进程组 |
| 路径/命令 | PowerShell参数和本机实际路径 | POSIX shell参数和本机实际路径 |
| 浏览器 | 遵循用户/项目明确选择及配套Skill，查实际能力 | 同左，不从操作系统推断已安装Ego/Chrome或已登录 |

已有四个支持脚本内置Windows/POSIX条件分支，保留一份实现；不为系统差异复制两套业务规则。显式指定Ego/Chrome时不静默切换浏览器（在 Ego 里新建/更换自己的测试空间不算切换，不问用户，见[新开测试空间不用问](machine-load.md#一遇到被占用要排队立刻新开一个绝不等待用户-2026-10-23最高优先)）；默认路线继续按[手机触屏Skill](../../mobile-touch-computer-use/SKILL.md)，Chrome路线读[Chrome工具](../../chrome-mobile-testing/SKILL.md)。Windows实测不替代Mac运行或手机/IAA证据。

## 接收Mac新改动时

保留共同基线、本机当前版本、Mac输入版本三份指纹；做三方差异，不按修改时间覆盖。逐项区分通用行为修复、系统适配、机器本地配置与单游戏事实。通用规则经验证进入共享核心；路径/命令走系统分支，本机配置留本机，单游戏数据留项目。

遇到同一规则的不同优化，以可复现任务、原始证据和适用范围裁定，不拼接两段互相矛盾的要求。目录/安装备份、Windows进程清理和Mac调用方式分别验证；跨系统的模拟分支检查仅证明路由逻辑。完成后仍用同一套核心版本和同一入口，两端各记实际运行验收范围。共享内容只含规则、通用脚本和公开模板；虚拟环境、缓存、账号状态、机器本地配置与单游戏生产进度不进入共同核心。
