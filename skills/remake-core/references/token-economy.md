# 省Token执行规则

可计数的硬规则（不轮询、总控只调度、阶段交接、输出上限、复测依赖、高风险样板、用户要求才打包与预算）见[执行节流](execution-budget.md)，与本页冲突时以它为准。

默认目标是减少无关上下文和重复工作，同时保留原制作/验收标准。字符/字节减少只是输入体积指标，不直接等同Token或账单节省；Grok也有自己的用量，协调和主线核验不能忽略。

## 默认只读当前阶段

开工读短SKILL入口、当前游戏的精简状态/相关规则、当前步骤细则。全量英文、UI生图、视觉、触控、IAA与打包各在进入时加载。已读且未变的文件本轮不重复cat；`rg`先定位标题/符号，再读相关范围。详细旧流程原文仅查当前标题，不通读三个workflow-detail.md。所有必要阶段仍完成；省Token不省掉当前步骤的规则或原始证据。

项目AGENTS只放稳定约束和导航，游戏版本/包SHA/旧测试留实体/来源页。开始新游戏用独立工程目录和新空白对话；同一游戏阶段结束时，沿用现有进度文件保存短交接，包含目标/实际路径/当前版本/已做与待做/问题和证据链接，不抄整段聊天。继续时读短交接和必要原件；新证据冲突回到原件。不要每轮给Agent粘贴所有游戏历史。进度页只留当前版本/问题/下一动作，旧待决与旧“下一步”移入日志并标替代关系；不让当前结论与历史指令并列。阶段续接会增加首次非缓存输入，不按固定频率开新会话，工具可继续时自主接续。完整制作的总控、子会话分领域、路径独占与交接按[总控与子会话分工](session-relay.md)执行。

## 工具与结果

先限定当前游戏及目录，默认避开node_modules、虚拟环境、原始归档和证据快照树，只有直接相关才进入；本机依赖版本无变化且工具正常时复用环境记录。可准确解析的资源/中文候选扫描、批准映射、SHA/CRC/解包、固定回归用现成脚本。命令结果优先给退出码、数量和具体失败；完整日志落盘，只在失败处取范围，不把整份构建/编译bundle打进对话。正常且无新改动时不反复扩大自检；当前改动必要检查通过后交付。检查时机按[检查节奏](session-relay.md#检查节奏省token)，不跟着每次返回检查。

GUI只截图当前需判断状态和受影响组合，不为日志重复载入旧图片；完整视觉清单仍按原范围完成。缓存/本次界面/版本对应读回，不能为省上下文伪填验收。重复控件和同版已合格素材复用；不重复生图已合格资产，不用换模型重复评价同一结论。

输入指纹变化与用量复盘执行[工作流工具](workflow-tools.md)；快照只选择复测范围，不生成pass。不要把等待/相同命令计数当成可删除调用。

## 外部任务

按[可选Grok](optional-grok.md)只给窄任务：目标、原始输入精确范围、规范/断言、允许写路径、完成条件和结果路径。原件保留完整；不能先让模型筛选/压缩原文，导致主线只看其留下的证据。执行者返回少量结果字段/异常/证据路径，主线仍核实际原始结果；长日志由工具处理，不再请模型总结一遍。

Grok默认一次一项、回执最多一层，禁止套娃Agent。任务所省输入若不足以抵消拆分/等待/核验成本，直接主线完成；没有固定委派比例。完全单应用明确禁外部调用；缺Grok不反复探测或提示安装。桌面模式不是默认七家全开。

## 不能承诺的节省

入口缩短可测量的是字节/字符；实际Token、缓存输入、输出、模型调用和费用若需比较，按同类任务/阶段实测。缓存输入已计入总输入，不能重复相加；订阅额度与Token记录不直接互换。本次规则精简不会自动清空已经很长的对话，新建会话实际加载后才体现默认输入减少。
