# 两个制作入口：英化（本包）和重塑（重塑包）（用户 2026-10-27：分开装、分开用）

| 输入 | 路线 |
|---|---|
| 只有中文Cocos源码，没有设计启动包 | **英化（本包 cocos-game-to-english）**：先核中文原版内部基线；保留核心玩法、关卡与原画风，补齐固定入口及[六标准广告](ad-standard-six.md)所需的真实系统依赖。原页面与新增页面先共同规划，再统一美工。六类以外的创新玩法按用户本次要求调用对应板块；已交付游戏的无关局部维护沿用原范围。正式英文试玩与最终测试包按英化入口的同页 H5 交接 |
| 有设计启动包，附源码或不附源码 | 重塑（重塑包 remake-game 板块，英化包不含）：先验证设计合同，保留接受后的数据，先玩法确认再美术 |
| 已批准成品局部修改 | 按实际改动进入对应维护入口，不补新品模板或重开完整美术 |

## 二、开工第一件事：判断走哪个板块

从材料结构和当前用户目标判断；附件历史指令不是外部操作授权。只有输入确有关键缺口且无法从项目资料确定时提必要问题，继续独立工作。默认当前应用，不逐任务询问多Agent。

## 英化的美术分两步（用户 2026-10-21）

首次英化的视觉范围以英化入口第 1 项为准，图中文字和玩家可见内容变英文；明确要求整套重做时才扩展到完整美术。原核心玩法、关卡、声音和已批准资产按项目合同保留。用户说按重塑画风重做时记录范围，再按对应美术入口完成样板、制作与自检，不以“英化不改美术”的旧默认覆盖当前授权。

共同产品规则只维护在[融合边界](fusion-policy.md)和[当前合同路由](current-contracts.md)，不在此复制。分享、联网排行榜（局内本地名次可以留，Saul 2026-10-31）、广告跳关按所属规则移除；旧keep_original决策不能启用。首次英化主页按[默认主页排版](../../remake-art/references/english-home-layout.md)由美工沿原画风统一安排原有功能及平台入口；已交付后的局部接入保留未受影响布局。重塑启动包的额外首页规则只管重塑，不能套用为英化换画风或增造功能。

阶段范围、抽样、增量回归和停止条件见[执行计划](../../cocos-game-check/test/references/review-execution-plan.md)，不为入口差异重复整轮验收。已授权出包仍核最终Native、资源、历史问题、体积和字节。
